        About

        Student Finance Tracker helps a student record expenses, stay under a spending cap and find past purchases with regular expressions. It runs entirely in your browser and stores data in localStorage; no account or server is needed.

        Built with

        HTML5, CSS3 (Flexbox and media queries) and vanilla JavaScript ES modules. No frameworks or charting libraries.

        Features

        • Validated add and edit form with regular-expression rules
        • Live, safe regex search with highlighted matches, category filter and sorting
        • Dashboard with totals, category breakdown, seven-day chart and cap tracking
        • Multiple currencies with manual exchange rates
        • Validated JSON export and import
